«Шальи» (инородные тела) причиняют вред уму и телу. Средством для извлечения различных шальев, застрявших в разных частях тела, служат «янтры» (инструменты); они применяются при геморрое, свищах и подобном; при применении режущих орудий, щёлочи, огня; для защиты остальных частей тела; а также при постановке клизмы и подобном — здесь используются рог, тыква-горлянка, горшочек и подобное; при операциях с губами используются инструменты типа «джамбавоштха» и подобные. Есть и другие приспособления, многообразные по форме и назначению, служащие инструментами для здоровых и больных. Поэтому, из-за разнообразия их применения, определить их точное число невозможно.

В этом случае инструменты «свастика» имеют головки в форме различных диких зверей — цапли, льва, грифа, орла и подобных, названные соответственно их форме; как правило, изготовлены из железа, длиной восемнадцать пальцев, с краями в форме чечевицы, скреплены штифтом на шее, у основания загнуты подобно крюку, — предназначены для извлечения застрявших в кости шальев. Инструменты с головками льва, тигра, крокодила и подобных следует применять при извлечении видимых снаружи застрявших шальев; в прочих же случаях — соответственно форме раны, применяются инструменты с головками цапли, вороны, орла и подобных.

«Аршоянтра» (геморроидальный инструмент) трёх видов: из меди, железа или золота, или из слоновой кости, рога, дерева, — в форме коровьего вымени, четыре пальца длиной; один размером с ладонь, окружностью пять пальцев для мужчин, шесть — для женщин; с двумя отверстиями — для осмотра, с одним отверстием — для хирургического действия. Ибо так обеспечивается удобство осмотра и точность применения режущего орудия, щёлочи, огня. Отверстие же — три пальца длиной, шириной с толщину большого пальца; из оставшегося пальца, половина — ниже, половина — выше отверстия, с выступающим краем-карникой высотой в половину пальца. Третий же инструмент, такой же, называемый «шамья», без бокового отверстия, — для сжатия. При свище же следует изготовить подобный инструмент, но с удалённым верхним краем от отверстия. Подобным же образом устроен и «гхранаршо-арбуда-янтра» (инструмент для носовых полипов) — в форме трубки, два пальца длиной, с одним отверстием, окружностью с указательный палец.
