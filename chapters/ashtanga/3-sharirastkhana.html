В каждой конечности число сир (вен) – сто; из них четыре, а именно одна по имени Джаландхара и три глубоко расположенные, не должны рассекаться (для кровопускания). В пришртха (спине) – дважды двенадцать, то есть двадцать четыре, по обеим сторонам позвоночного столба; среди них по две с каждой стороны, идущие вверх, не следует затрагивать. В джатхара (животе) – столько же, сколько в спине; из них по две с каждой стороны, расположенные над половым членом по обе стороны линии волос, не следует затрагивать.
