## О проекте

Проект начинался как читатель «Аштанга-хридая-самхиты», а сегодня это крупнейший бесплатный русскоязычный портал аюрведических первоисточников: **7 классических самхит**, **34 541 шлока** в оригинале и переводе, энциклопедия из **208 статей**, **382 термина** глоссария с IAST-транслитерацией, глоссарий **66 болезней** и **113 домашних средств**.

Фронтенд — статический одностраничный сайт на чистом JavaScript (ES-модули), работает прямо в браузере, без регистрации и установки. Динамические функции (вход эксперта, краудсорс-правки, подписка, ежедневный пост) обслуживаются лёгким бэкендом (serverless-функции на Vercel либо Node/Express на VPS) и Telegram-ботом.

## Разделы приложения

### Библиотека — единый читатель

- Навигация по **тексту → стхане → главе** в боковой панели с раскрывающимися группами
- Визуальное разделение **шлок** (стихов), **прозы** и **комментариев**
- **Полнотекстовый поиск** по всем главам в реальном времени с подсветкой
- **Санскритские термины** в тексте кликабельны — тултип с определением и IAST
- Переключение между книгами и темами без перезагрузки

### Глоссарий терминов

**382 термина** с определениями, IAST-транслитерацией и примерами: доша, агни, прана, анатомия, растения, препараты, практики, диагностика.

### Глоссарий болезней

**66 болезней** аюрведической нозологии: санскритское название и IAST, задействованные доши, патогенез, симптоматика, методы лечения, ссылки на первоисточники.

### Домашние средства

**113 заболеваний** с рецептами трав, специй, масел и диет для самостоятельного применения; блоки «ВНИМАНИЕ!» выделены, артефакты PDF-переноса вычищены.

### Энциклопедия

**208 статей по 43 разделам** — авторский синтез десятков книг по аюрведе.

### Дополнительно

- **Литература** — библиография источников
- **Расписание питания** — суточные ритмы по дошам
- **Тест конституции (пракрити)** — определение типа

## Возможности чтения

- 🔍 **Поиск** по всему тексту книги с подсветкой
- 🔗 **Поделиться** стихом / статьёй / средством / термином (цитата + источник + ссылка) и **постоянные ссылки** (permalink) на конкретный стих с переходом и подсветкой
- 🔊 **Озвучка стиха** (TTS) — выбор голоса по языку
- 📿 **Стих дня** и **«Продолжить чтение»** на главной
- 🅰️ **Размер шрифта** (А / А+ / А++)
- 🧭 **Навигация по длинным главам** — переход к стиху по номеру и кнопка «наверх»
- 🌙 **Тёмная тема**
- 📡 **PWA / офлайн** — Service Worker кеширует прочитанное, приложение ставится на домашний экран

## Кабинет эксперта

Закрытый раздел для проверенных специалистов (вход через Telegram):

- **Правки текста** — предложения исправлений к шлокам и переводам с модерацией
- **Авторские статьи** — добавление материалов в энциклопедию, глоссарий и домашние средства
- **Краудсорс-перевод** санскрит-только книг (наполнение поля перевода сообществом)

Подробнее об активации, ролях и переменных окружения — в [`EXPERT_CABINET.md`](EXPERT_CABINET.md).

## Telegram-бот и канал

- **Бот** (Telegraf) — поиск по текстам и вход в кабинет эксперта
- **Ежедневный пост** в канал — стих с оригиналом, IAST и переводом (cron 09:00 и 18:00 UTC)

Токены и секреты хранятся **только** в переменных окружения (`bot/.env` локально, env-vars на хостинге) и никогда не попадают в репозиторий.

## Источники

Тексты извлечены из оригинальных печатных и оцифрованных изданий, структурированы и адаптированы для чтения:

- **GRETIL** (Göttingen Register of Electronic Texts in Indian Languages) — выверенные санскритские корпуса
- **Sanskrit Wikisource** — деванагари Бхавапракаши и др. (MediaWiki API)
- **archive.org** — полные сканы (английский перевод Сушруты, OCR)
- **K. L. Bhishagratna** — английский перевод Сушрута-самхиты
- **Vasant Lad**, «Домашние средства аюрведы» — база домашних средств
- IAST-транслитерация — `indic_transliteration` (Sanscript)

## Технический стек

**Фронтенд:** чистый JavaScript (ES-модули), без фреймворков и сборки. Кеш-бастинг — версионирование импортов (`?v=N`). PWA: `manifest.json` + Service Worker (`sw.js`).

**Бэкенд:** serverless-функции в `api/` (11 шт., в пределах лимита Vercel Hobby ≤ 12) либо Node/Express (`server.js`) на VPS. Хранилище — Vercel KV (Redis-совместимое). Платежи — ЮKassa.

**Бот:** Node + Telegraf (`bot/`), запуск polling (`npm run bot`).

| Группа | Функции `api/` |
|---|---|
| Контент | `book-data`, `overrides` (правки + статьи) |
| Аккаунт / доступ | `auth-telegram`, `entitlements` |
| Оплата | `pay-create`, `pay-webhook`, `sub-cancel` |
| Сообщество | `proposals` |
| Бот / автоматизация | `webhook`, `daily-post` |
| Диагностика | `health` |

## Запуск локально

**Только фронтенд** (статика, без бэкенд-функций):

```bash
python3 serve.py          # или любой статический сервер
# открыть http://localhost:8000
```

**Полностью** (фронтенд + API + cron, как на VPS):

```bash
npm install
npm start                 # Express на :3000 (PORT настраивается)
npm run bot               # отдельно: Telegram-бот (нужен BOT_TOKEN в bot/.env)
```

Динамические функции требуют переменных окружения (см. [`EXPERT_CABINET.md`](EXPERT_CABINET.md)). Без них фронтенд и чтение работают полностью; кабинет/оплата/бот — выключены.

## Деплой

- **Vercel (текущий прод):** статика + `api/` как serverless-функции; cron `daily-post` по `vercel.json`; секреты — в env-vars проекта. Важно: на тарифе Hobby лимит **≤ 12** функций.
- **VPS (Node):** `server.js` поднимает Express (раздаёт статику, монтирует те же `api/*`, шлёт ежедневный пост через `node-cron`). Рекомендуется PM2 + Nginx (отдача статики и проксирование `/api`). Бот — отдельным процессом в режиме polling.
