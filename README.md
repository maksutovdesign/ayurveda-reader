В базе — **24 295 санскритских шлок** с переводами, комментариями и интерактивными инструментами.

## О проекте

Проект начинался как читатель «Аштанга-хридая-самхиты». Сегодня это крупнейший бесплатный русскоязычный портал аюрведических первоисточников: **7 классических текстов**, **24 295 шлок** в оригинале и переводе, полная энциклопедия из 208 статей, 382 санскритских термина с IAST-транслитерацией, глоссарий 66 болезней и 113 домашних средств.

Все материалы извлечены из оригинальных печатных изданий вручную, структурированы и адаптированы для чтения на русском языке. Никаких внешних API, баз данных или подписок — всё работает как статический сайт прямо в браузере, без регистрации.

## Разделы приложения

### Библиотека — 7 классических канонов

Единый интерактивный читатель для всей библиотеки.

- Навигация по **тексту / стхане / главе** в боковой панели с раскрывающимися группами
- Визуальное разделение **шлок** (стихов), **основного текста** и **комментариев**
- **Полнотекстовый поиск** по всем главам в реальном времени с подсветкой совпадений
- **Санскритские термины** подчёркнуты пунктиром — тултип с определением и IAST-транслитерацией
- Переключение между текстами без перезагрузки страницы

**Аштанга-хридая-самхита** (Вагбхата, VII в.) — «Суть восьми разделов». Физиология, диагностика, терапия, фармакология, хирургия и духовные практики.

| Раздел (стхана) | Содержание |
|---|---|
| Сутрастхана | Основные принципы аюрведы |
| Шарирастхана | Анатомия и физиология |
| Нидана стхана | Диагностика болезней |
| Чикитса стхана | Методы лечения |
| Калпасиддхистхана | Рецептура и приготовление |
| Уттара стхана | Специальные разделы |

**Чарака-самхита** — древнейший дошедший до нас аюрведический трактат. Фундаментальная медицинская система: учение о трёх дошах, пяти элементах, ста болезнях и методах их лечения.

**Астанга-санграха** — параллельная версия Вагбхаты с подробными прозаическими комментариями. Самая большая база в проекте: **9 262 шлоки** в 150 главах.

**Мадхава-нидана** — классика аюрведической диагностики. 69 глав о природе, причинах и симптомах болезней.

**Шарангадхара-самхита** — средневековая фармакопея. Рецептура, классификация лекарств, дозировки, методы приготовления.

**Сушрута-самхита** — основа аюрведической хирургии. 184 главы: анатомия, хирургические инструменты, операции, офтальмология, педиатрия.

## Технический стек

Чистый **HTML / CSS / JavaScript** — никаких фреймворков, сборщиков и зависимостей.

- **ES-модули** — код разбит на независимые `.js` файлы, импортируемые нативно
- **CSS Custom Properties** — полная дизайн-система на переменных; тёмная и светлая тема
- **SPA без роутера** — навигация через `history.replaceState` и хэш-фрагменты
- **localStorage** — сохранение темы и позиции чтения
- **Tooltip-система** — позиционирование с учётом краёв экрана, touch-поддержка
- **Парсер текста** — state-machine для PDF/OCR артефактов: склейка строк, детекция ингредиентных списков
- **Кабинет экспертов** — Telegram Login Widget + HMAC-подпись + Vercel KV (Upstash Redis)

## Запуск локально

Приложение использует ES-модули — требует HTTP-сервер (не `file://`).

```bash
# Python (встроен в macOS и Linux)
python3 -m http.server 3333

# Node.js
npx serve .

# Затем открыть
open http://localhost:3333
```

## Возможности интерфейса

- **Тёмная / светлая тема** — переключение кнопкой, сохраняется между сессиями
- **Поиск** — по всем 24 295 шлокам одновременно
- **Прямые ссылки** — каждый раздел доступен по URL с хэшем
- **Адаптация под мобильные** — адаптивная боковая панель
- **Копирование в буфер** — реквизиты доната копируются одним кликом
- **Медицинский дисклеймер** — фиксированный блок в подвале
